더커스텀 운영 매뉴얼 · 읽기용

실행 방법
1. index.html을 브라우저에서 직접 열어도 됩니다.
2. 더 안정적으로 실행하려면 이 폴더에서 CMD/PowerShell을 열고 아래 명령을 실행하세요.
   python -m http.server 8080
3. 브라우저에서 http://localhost:8080 접속

기능
- 13개 읽기 페이지
- 좌측 목차 / 다음·이전 페이지
- Ctrl+K 전체 검색
- 페이지별 우측 목차
- 글자 크기 조절
- 인쇄 지원
- 읽기 진행도 자동 저장
- 첨부 화면 확대 보기

사용 이미지
- 사유지 지도
- 정비소 거래상
- 제작대
- 제작 UI
- 재료 거래상
- 출동 태블릿 설정/알림 화면
- 디스코드 음성 설정
- 인트라넷 보고서 화면
